# Overview

Version 1 of Yashita Namdeo's personal portfolio website. Built with Gatsby (React-based static site generator) and deployed via GitHub Pages.

Quick start:

- `gatsby-cli`, Node via `nvm install`, then `yarn` to install deps.
- `npm start` for dev, `npm run build` + `npm run serve` for production preview.

Styled around a dark navy palette (see the color reference table in `README.md`). Design inspired by brittanychiang.com.
