# Overview

Version 1 of Yashita Namdeo's personal portfolio website. Built with Gatsby (React-based static site generator) and deployed via GitHub Pages.

Quick start:

- `npm install -g gatsby-cli`, `nvm install`, then `yarn` to install dependencies.
- `yarn start` for development, `yarn build && yarn serve` for production preview.

Styled around a dark navy palette (see the color reference table in `README.md`). Design inspired by [brittanychiang.com](https://brittanychiang.com).
